# 12 · Thêm một gói (hợp đồng gói) + tiêu chí nghiệm thu trước phát hành

Lõi + gói là code dùng chung mọi công ty; cấu hình từng công ty là dữ liệu (0056, 0059). Một gói MỚI (ngành hoặc năng lực) phải khai đủ các mục
dưới — thiếu mục nào thì test cấu trúc (`tests/test_meta.py`) hoặc test của gói phải bắt được. Không code riêng cho một công ty (0060).

Gói gọi ra một hệ ngoài (CRM, WordPress, CMS, tổng đài, sàn, hãng vận chuyển, nền quảng cáo): dùng KHUNG KẾT NỐI CHUNG — runbook 22. Gói không tự làm
bảng kết nối, chỗ giữ khoá, biến môi trường chứa khoá hay cửa webhook riêng (`Module.inbound` chỉ còn cho khung; test cấu trúc chặn).

## Nghiệm thu trước phát hành (đụng tiền / quyền / gói / migration)

1. `bash deploy/release.sh CHECK_ONLY=1` — đủ test trên checkout riêng của đúng commit.

## Danh mục gói chưa cài (Store — 0163)

Store hiện cả gói bản cài CHƯA có ("Chưa có trên bản cài · Liên hệ") nhờ `backend/src/barista/pack_catalog.json` — file CHỮ do `python3 deploy/packs.py bundle …`
