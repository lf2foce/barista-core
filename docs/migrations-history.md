# Lịch sử migration trước bản gốc (001–186)

Ngày 05/11/2026 toàn bộ chuỗi migration được gộp thành bản gốc `backend/src/barista/migrations/000_baseline/` (quyết định
0085). Bảng dưới là mục lục chuỗi cũ: số, tên, dòng mô tả đầu file. Nguyên văn một file:

```
git show 988c216:backend/src/barista/migrations/<tên file>
```

Lý do của từng thay đổi nằm ở `barista-docs/decisions/` (file migration thường nhắc số quyết định).

Từ 0130 (08/11/2026) migration nằm theo GÓI: bản gốc ở `migrations/base/000_baseline/`, dãy `001…` sau bản gốc chia vào `migrations/<gói>/`
theo module dòng đầu (giữ nguyên tên + nội dung; `031_talk_daily` ở gói nền vì 040–042 của nền dựa vào nó). Sổ dãy số chung cũ
(`public.barista_migrations`) tự ánh xạ sang sổ theo gói. Số `mig NNN` trong ADR / ROADMAP cũ trỏ vào bảng này.

Đổi tên chỉ để sửa chú thích (16/11/2026, ADR 0233): `base/054_rls_initplan.sql` ⇒ `base/054_rls_initplan_core.sql` (thân SQL giữ nguyên,
dòng đầu bỏ tên khách) qua `base/provenance.json` (tên cũ + checksum bản cũ) — bản cài đã chạy bản cũ không chạy lại gì.
